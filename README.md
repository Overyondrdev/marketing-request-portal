# Yondr marketing request portal

The portal where anyone at Yondr requests marketing work, gets it approved and follows it to delivery.
It will run at https://requests.overyondrdev.com (Cloudflare Worker + D1 + R2, behind Cloudflare Access).

The first version arrives through a pull request from the `claude/eager-volta-chwrdd` branch.
